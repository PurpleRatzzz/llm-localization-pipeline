# LLM Localization Pipeline with QA Gates

A small, reproducible EN→ZH translation pipeline built on Salesforce's public
[localization-xml-mt](https://github.com/salesforce/localization-xml-mt) dataset:
LLM translate → edit → verify stages, deterministic QA gates for XML tags,
placeholders, numbers and terminology, and XLIFF 1.2 handoff for human review.

Work in progress.
